# 开发什么：《鸿蒙未来城市探索馆》

---

## 零、先判断：报告网站 vs 数字展览

普通学生作品：

```
首页 → 团队介绍 → 调研照片 → 调研过程 → 成果展示 → 总结
```

这是**报告网站**。

我们想做的是：

```
一个人进入网站
    ↓
被带入一个城市问题
    ↓
跟随我们探索
    ↓
理解鸿蒙价值
    ↓
产生对未来城市的想象
```

这是**数字展览**。

> **本质：数字展览作品 / 科技叙事作品。**

---

## 一、整体主题

> **"寻找人与城市、人与设备之间新的连接方式。"**

### 定位

- ❌ 不是：社会实践成果汇报网站
- ❌ 不是：鸿蒙技术科普页
- ❌ 不是：调研过程流水账

- ✅ 是：以一次青年社会调研为入口，构建关于"城市数字化未来"的交互式叙事空间

### 用户情感曲线

```
问题 → 探索 → 发现 → 理解 → 想象 → 行动
```

---

## 二、Storyboard

---

### 第一幕：序章 —— 城市正在连接（约 30 秒）

**目标：让用户产生问题。** 不说鸿蒙，不说调研，先说城市。

#### 画面

```
黑色背景。

城市夜景慢慢亮起。
    东莞南城。
        道路。
        写字楼。
        社区。
        商场。
        家庭。

设备依次亮起，形成数据流：
    手机付款
        ↓
    车辆导航
        ↓
    智能门禁
        ↓
    生产设备运转
```

#### 字幕

> "今天，一座城市每天产生数以亿计的数字连接。"

停顿。

> "但连接，是否意味着真正的智慧？"

#### 然后

标题淡入：**鸿蒙未来城市探索馆**

按钮：`开始探索`

> 节奏参考：Apple 发布会开场——先制造问题，不给答案。

---

### 第二幕：走进南城 —— 我们在哪里寻找答案（约 1 分钟）

**目标：告诉用户——我们不是凭空想象，我们真的走进了城市。**

#### 画面

不是普通地图，是一张**探索地图**。

```
中心：
    东莞南城
    2026 夏

周围探索节点：

    ● 产业观察点
    ● 社区观察点
    ● 商业观察点
    ● 公共服务观察点
```

#### 引导文字

> "我们希望了解：当设备越来越多，城市如何真正连接起来？"

#### 点击节点 → 进入下一幕

---

### 第三幕：田野调查 —— 我们看到了什么（约 2-3 分钟）

**目标：对应真实实践。** 不做照片墙——用"发现卡片"。

#### 每张卡片三层结构

```
┌──────────────────────────────┐
│                              │
│   [现场照片]                  │
│                              │
│   我们观察：                 │
│   设备越来越智能，但不同设备   │
│   之间仍然存在隔阂。          │
│                              │
│   我们思考：                 │
│   如果设备能够理解彼此，      │
│   城市服务是否可以更加主动？  │
│                              │
│   未来：                     │
│   一个入口连接家庭、社区、    │
│   医疗。                     │
│                              │
└──────────────────────────────┘
```

#### 四个场景

| 场景 | 现实 | 问题 | 思考 |
|------|------|------|------|
| 社区 | 老人不会操作多个 App | 数字服务门槛 | 一个入口连接家庭、社区、医疗 |
| 企业 | 设备系统各自独立 | 数据无法流动 | 设备之间是否可以自然协同 |
| 商业 | 线上线下体验割裂 | 服务碎片化 | 跨场景无缝体验 |
| 政务 | 信息不透明 | 响应滞后 | 城市感知与主动服务 |

> 格式统一：**现实场景 → 问题发现 → 技术思考**

---

### 第四幕：鸿蒙洞察 —— 连接的新方式（核心高潮，约 3 分钟）

**这里才第一次出现鸿蒙。**

#### 标题

> **从设备智能，到万物互联**

#### 核心动画

```
传统模式（孤岛）：

    手机          电脑          汽车
     │             │             │
    App1         App2         系统3

    ↑ 每个都是孤岛 ↑


鸿蒙理念（协同）：

                人
                 │
                 ↓
        手机 ←→ 平板 ←→ 车 ←→ 家庭设备
                 │
                 ↓
               服务

    ↑ 设备从独立智能走向协同智能 ↑
```

#### 表述方式

不是："鸿蒙解决所有问题。"

而是：

> "鸿蒙提供了一种新的技术思路：让设备从独立智能走向协同智能。"

#### 问题-技术对应表

| 城市问题 | 技术思考 |
|----------|----------|
| 设备孤岛 | 设备协同 |
| 服务割裂 | 跨设备体验 |
| 信息不透明 | 数据连接 |

---

### 第五幕：数据实验室 —— 调研证据（约 1 分钟）

**目标：展示专业性。** 不是"采访了 20 人"——做成**城市数字观察报告**。

#### 动态数字

```
    15          37          1280         56          12
  调研场景     访谈记录     分钟交流     问题标签    未来场景
```

#### AI 生成城市需求图谱

```
        智慧养老
        ★★★★★

  设备协同          数字服务
   ★★★★             ★★★★
```

---

### 第六幕：AI 调研员 —— 让成果继续生长（约 2 分钟）

**目标：展示这是一个"可持续研究平台"，不只是网页。**

#### 入口画面

一个鸿蒙机器人形象：

> "你好，我是本次调研的数字助手。"

#### 交互

```
用户输入：南城智慧社区最大的挑战是什么？

AI 回答：
    根据 5 次社区访谈记录，我们发现主要问题集中在
    设备使用复杂度和服务入口分散。

    [引用：访谈照片] [引用：调研笔记]
```

#### 知识来源（必须绑定团队数据）

```
访谈记录 + 照片 + 调研笔记
    +
问卷数据 + 政策文件 + 鸿蒙资料
    ↓
知识库
    ↓
AI 助手
```

> **关键区分：** 不是接 GPT API —— 评委问"和 ChatGPT 有什么区别？"时，回答可溯源到具体调研内容。

---

### 第七幕：未来南城 2035 —— 青年想象（终章）

**目标：不预测未来，展示设计思考。**

#### 画面

```
现在南城
    ↓
  慢慢变化
    ↓
未来南城：

    智慧交通 ─── 车辆成为城市节点
    智慧社区 ─── 家庭成为服务入口
    智慧教育 ─── AI 成为学习伙伴
```

#### 终场

黑屏。一行字：

> "我们调研的不只是今天的鸿蒙。"

停顿。

> "而是未来十年，人与城市连接的方式。"

---

### 尾页：青年未来宣言

不是"感谢观看"。

而是：

> "技术的价值，不在于创造更多设备，
> 而在于让人与世界建立更自然的连接。"

---

## 三、用户完整体验流

```
第一幕  序章        提出问题    "城市连接了，但智慧了吗？"
                         ↓
第二幕  走进南城     开启探索    "我们在哪里寻找答案？"
                         ↓
第三幕  田野调查     发现矛盾    "设备多了，连接没跟上。"
                         ↓
第四幕  鸿蒙洞察     理解技术    "协同智能，而非独立智能。"
                         ↓
第五幕  数据实验室   验证观点    "这不是空谈，有数据支撑。"
                         ↓
第六幕  AI 调研员   持续对话    "成果不是死的，可以生长。"
                         ↓
第七幕  未来南城     想象可能    "青年如何设计未来城市？"
                         ↓
尾页    青年宣言     留下思考    "技术，为更自然的连接。"
```

## 四、动工之前，先做三件事

**不要直接写代码。** 先做：

### 1. 导演分镜表（Excel）

| 幕 | 用户看到什么 | 想表达什么 | 情绪目标 | 技术 |
|----|------------|-----------|---------|------|
| 序章 | 城市夜景 + 数据流动画 | 提出"连接≠智慧"的疑问 | 好奇、悬念 | Three.js |
| 走进南城 | 探索地图 + 节点 | 真实调研，非凭空想象 | 信任感 | Mapbox / Three.js |
| 田野调查 | 发现卡片 ×4 | 从观察到思考的逻辑链 | 共鸣 | React + 动画 |
| 鸿蒙洞察 | 孤岛→协同动画 | 鸿蒙的独特价值 | 理解、豁然 | Three.js / Canvas |
| 数据实验室 | 动态数字 + 需求图谱 | 数据支撑观点 | 信服 | D3.js / ECharts |
| AI 调研员 | 对话界面 + 溯源引用 | 成果可持续生长 | 惊喜 | LLM + RAG |
| 未来南城 | 城市变化动画 | 青年设计思考 | 想象力 | Three.js 场景 |
| 尾页 | 宣言文字 | 留下核心观点 | 回味 | CSS |

### 2. 内容资产收集

现在最重要的不是代码，是内容：

- [ ] 调研照片（高质量，分类：社区/企业/商业/政务）
- [ ] 视频素材
- [ ] 访谈文字（标注来源、时间、地点）
- [ ] 问卷数据（可用数字呈现的）
- [ ] 鸿蒙技术资料（准确的技术表述）
- [ ] 未来概念参考图

### 3. 视觉统一

**关键词：** 华为发布会 × Google Arts & Culture × 青年科技探索

| 元素 | 规范 |
|------|------|
| 主色 | 深黑 `#0a0a0f` |
| 辅色 | 星云蓝 `#1a1a3e` |
| 强调 | 鸿蒙紫 `#6c5ce7` |
| 字体 | 白 `#ffffff`，透明度分级 |
| 字号 | 标题 48-64px，正文 16-20px，数据 72px+ |
| 动效 | 缓入缓出，不炫技，服务于叙事节奏 |
| 间距 | 大量留白，每屏一个焦点 |
