# 《鸿蒙未来城市探索馆》完整页面 UI 草图

> 本文档直接指导前端开发。每一页 = 布局 + 动画 + 文案 + 技术。

---

## 全局设计系统

### 色彩

```
深黑背景    #0a0a0f    — 主背景
星云蓝      #1a1a3e    — 卡片、次级背景
鸿蒙紫      #6c5ce7    — 强调、按钮、高亮
科技蓝      #4a9eff    — 数据、链接、交互
白          #ffffff    — 正文，透明度分级：
             100% — 标题
             80%  — 正文
             50%  — 辅助信息
             30%  — 装饰线
```

### 排版

```
标题    48-64px   font-weight: 700   letter-spacing: 2px
副标题  28-36px   font-weight: 500
正文    16-20px   font-weight: 400   line-height: 1.8
数据    72-96px   font-weight: 700   letter-spacing: 1px
```

### 动效原则

```
缓动函数    cubic-bezier(0.4, 0, 0.2, 1)  — 所有过渡统一
时长        卡片入场 0.6s / 文字淡入 0.8s / 场景切换 1.2s
节奏        先背景 → 再主体 → 最后文字（逐层带入）
滚动触发    元素进入视口 30% 时触发动画
```

### 交互原则

```
每屏一个焦点   — 用户不需要选择看哪里
滚动为主       — 少用点击，多用滚动叙事
悬停有反馈     — 卡片悬停 = 微放大 + 发光边框
过渡有意义     — 切换场景时有承接元素，不黑屏跳转
```

## 页面 1：序章 —— 城市正在连接

### 布局

```

画面从中心展开。

    数据流颜色：科技蓝 #4a9eff

阶段 C（5-12s）：
    画面分为上中下三层：

    上层（画面 70%）：
        城市夜景，数据流持续流动
        依次亮起：
            📱 手机付款场景（画面右上方闪现）
            🚗 车辆导航（画面下方移动光点）
            🏠 智能门禁（画面左侧亮起）

        第一行字幕出现：
        "今天，一座城市每天产生数以亿计的数字连接。"
        字体：24px，白色 80%，逐渐淡入

        停顿 1.5s

        第二行字幕替换：
        "但连接，是否意味着真正的智慧？"
        字体：36px，白色 100%，字重 700
        停留 2s

    下层（画面底部 15%）：
        标题淡入：
        "鸿蒙未来城市探索馆"
        字体：56px，白色，letter-spacing: 4px
        下方出现按钮：
        ┌──────────────┐
        │   开始探索    │
        └──────────────┘
        按钮：透明背景，1px 白色边框，hover 变鸿蒙紫填充
```

### 动画时间线

```
0.0s    城市线框升起（从底部，duration 1.5s）
1.5s    数据流开始（持续循环）
3.0s    第一个设备场景亮起（手机付款）
4.5s    第二个（车辆导航）
6.0s    第三个（智能门禁）
7.5s    第四个（生产设备）
8.0s    第一行字幕淡入
9.5s    第一行字幕淡出
10.0s   第二行字幕淡入（更大、更强调）
12.0s   标题 + 按钮淡入
```

### 交互

```
点击"开始探索" → 过渡到页面 2
滚动也触发过渡（滚动 = 确认继续探索）
```

### 技术

```
Three.js 场景（城市线框模型 + 粒子数据流）

```

```
子场景 A：

```
