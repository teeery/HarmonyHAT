# 三、低成本技术路线（推荐）

不要 Three.js 建城市。

采用：

## Layer分层法

类似设计软件。

你的地图由5层组成：

```
Layer 5
交互节点


Layer 4
数据流动画


Layer 3
道路/区域线条


Layer 2
城市底图


Layer 1
背景氛围
```

---

## Layer 1：背景

最简单。

一个渐变：

```css
background:

radial-gradient(
circle,
#142850,
#030712
);
```

加：

粒子。

# 五、核心组件设计

## 1. ExploreNode

这是灵魂。

例如：

企业节点：

```jsx
<ExploreNode

icon="building"

title="企业"

desc="鸿蒙产业需求"

/>
```

效果：

默认：

一个光点。

Hover:

扩大：

```
✦
 ↓

企业

鸿蒙产业需求
```

---

动画：

Framer Motion:

```jsx
<motion.div

animate={{

scale:[1,1.2,1]

}}

transition={{

duration:2,

repeat:Infinity

}}

/>
```

形成呼吸光。

# 六、地图连接线怎么做？

非常简单。

SVG：

```jsx
<svg>

d="M200 300 Q400 100 600 300"

/>

```

CSS：

```css
stroke-dasharray:500;

animation:
flow 5s linear infinite;
```

效果：

数据流动。
