如果你准备**AI辅助快速开发**，首页不要一开始就追求“三维城市”。因为首页是整个作品的**第一印象 + 叙事入口**，但也是最容易被AI生成得“廉价”的地方。

我建议首页先做一个**Apple发布会式的 Hero Scene（开场章节）**。

目标：

用户打开网页 5 秒内产生：

> “这不是一个学生报告，这是一个科技展览。”

---

# 首页定位

## 名称：

《鸿蒙未来城市探索馆》

## 首页不是介绍项目

而是：

> **提出一个关于未来城市的问题。**

# 背景怎么做？

最重要。

不要找素材。

直接AI生成。

Prompt：

```
未来东莞南城智慧城市夜景，
大量蓝紫色数据流连接建筑，
城市道路形成光轨，
智能设备网络节点，
科技发布会视觉，
Apple keynote 风格，
高级简洁，
无文字，
16:9
```

然后作为：

background-image。

# 动效设计

三个就够：

## 1. 背景缓慢移动

类似：

城市在呼吸。

CSS：

```css
background-position:
animation:move 20s infinite;
```

---

## 2. 数据光线流动

加一个透明渐变层：

```
linear-gradient
```

不断移动。

---

## 3. 文字出现

Framer Motion:

顺序：

```
标题
↓
副标题
↓
按钮
```

间隔：

0.3秒。

# 但是我要提醒一个关键点

首页不要做成：

“鸿蒙宣传页”。

否则评委会觉得：

> 这是华为广告。

首页真正应该表达：

```
城市变化
    ↓
产生问题
    ↓
我们开始探索
```

鸿蒙是在后面出现。

---

所以首页第一版目标：

不是：

“展示鸿蒙”。

而是：

**让用户愿意跟着你们走完一次城市探索。**

---

如果你使用AI开发，我建议下一步直接做：
**“首页完成后的第二幕：3D南城探索地图怎么低成本实现”**。

因为地图是整个网站从“漂亮网页”升级到“数字展馆”的关键。
