# 慕思健康睡眠 · 调研执行方案

> 时间：29号下午 16:00 — 18:00
> 地点：厚街镇
> 定位："鸿蒙智选"首批合作伙伴，鸿蒙智能床销售额过亿
> 预约：🔴 需书记提前联系慕思品牌部

---

## 场景前置信息（出发前发给全员）

慕思健康睡眠股份有限公司，东莞厚街本土上市公司。2025年成为华为"鸿蒙智选"首批合作伙伴，鸿蒙智能床上市第一年销售额突破1亿元，占智能床品类销量的40%。床体可无感联动灯光、空调、窗帘等鸿蒙设备，实时感知心率、呼吸、翻身、打鼾等生命体征，定位不再是"床垫"而是"睡眠中枢"。积累超100万条人体工学数据、10.8亿条睡眠大数据。

2026年5月，慕思联合马可波罗、东莞市家具协会、绿色建筑协会等在R&A PARK发起"开源鸿蒙家居产业生态合作倡议"——这意味着慕思的角色正从"鸿蒙智选的使用者"转向"鸿蒙家居生态的推动者"。

**关键概念：**

| 概念 | 一句话解释 |
|------|-----------|
| 鸿蒙智选 | 华为对品质/体验/生态协同达到高标准的第三方产品授予的认证标签——类似"鸿蒙生态的优品认证" |
| 无感联动 | 不需要手动操作，床感知到你躺下→自动关灯、调空调温度、拉窗帘 |
| 睡眠中枢 | 慕思的提法——床不只是寝具，而是全屋睡眠场景的"控制中心" |
| 人体工学数据 | 床垫记录的体压分布、脊柱曲度等，用来优化床垫设计 |
| 睡眠大数据 | 用户实际睡眠过程中的心率、呼吸、翻身次数、深浅睡眠时长等 |

> "从寮步智行中心到省适配中心再到慕思，恰好是一条链：鸿蒙怎么卖→鸿蒙怎么认证→鸿蒙怎么变成一个具体产品。到慕思这里，核心问题是——鸿蒙到底给一家传统制造企业带来了什么真金白银的价值。"

## 第二阶段：深度访谈


### 八个核心问题（80分钟，每题约10分钟）

| # | 问题 | 追问方向 | 负责 |
|---|------|---------|------|
| 1 | 慕思从决定做鸿蒙智联，到拿到认证、产品上市，全程走了多久？最耗时的是哪个环节？ | 和省适配中心说的"标准流程"对比——实际更快还是更慢？为什么？ | |
| 2 | 智能床要联动灯光、空调、窗帘——品牌各异、协议不同，你们怎么打通的？有没有实在接不进来的设备？ | 华为全屋智能（PLC）vs 第三方WiFi/Zigbee，接入难度差多少？用户家里已有的智能设备能复用吗？ | |
| 3 | 鸿蒙智选方案，和非鸿蒙方案（比如米家/涂鸦），对慕思来说最核心的差异是什么？ | 是技术更好？生态更大？认证背书？还是华为渠道的流量？ | |
| 4 | 10.8亿条睡眠数据——怎么存、怎么用、怎么保护？用户有没有因为隐私顾虑不敢买？ | 数据资产变现了吗（保险/医疗合作）？还是纯粹帮用户改善睡眠？用户能删数据吗？ | |
| 5 | 鸿蒙智能床销售额过亿、占智能床40%——这个成绩，鸿蒙贡献了多少？如果不挂"鸿蒙智选"四个字，能卖到这个数吗？ | 有没有对比数据？消费者是因为"慕思"买单还是"鸿蒙"买单？ | |
| 6 | 从"卖床垫"到"卖睡眠中枢"，鸿蒙扮演了什么角色？是催化剂、基础设施、还是营销标签？ | 如果没有鸿蒙，慕思的智慧睡眠转型会走什么路线？时间线会往后推多久？ | |
| 7 | 鸿蒙智能床售后怎么分工？床垫故障 + 传感器故障 + 鸿蒙连接故障——用户该找谁？ | 有没有实际售后纠纷案例？多品牌联动出问题时责任怎么界定？ | |
| 8 | 如果鸿蒙智选的政策红利退坡、或华为战略调整——慕思还会持续投入吗？鸿蒙给你们最不可替代的价值到底是什么？ | 慕思有没有做"去鸿蒙化"的Plan B？ | |

### 追问技巧

- **做对比**："省适配中心说适配周期一般是X个月，你们实际呢？"——上下游交叉验证
- **挖数据**：对方说"卖得好""用户喜欢"→ 立刻追问具体数字
- **找痛点**：对方说"挺顺利的"→ 追问"那最头疼的一件具体事是什么？"
- **探底线**：问题8是压力测试——看对方坚定还是犹豫，比前面7个问题都重要 |

### 追问技巧

- **做对比**："省适配中心说适配周期一般是X个月，你们的实际经历呢？"——上下游信息交叉验证
- **挖数据**：对方说"卖得好""用户喜欢"→ 追问具体数字
- **找痛点**：对方说"挺顺利的"→ 追问"那最头疼的一件事是什么？"
- **探底线**：问题8是整个访谈的"压力测试"——看对方是坚定还是犹豫
