## 场景前置信息（出发前发给全员）

广东省开源鸿蒙适配中心，2026年3月20日揭牌，经广东省政府批准设立的唯一全栈式开源鸿蒙产业协同中枢。采用"一中心+三基地"布局——广州黄埔总部 + 东莞基地 + 佛山基地，总投资1亿元。公益性质、企业化运作，由黄埔区属国企科学城数科集团牵头，联合佳都科技、电子五所、华为共建。

这个点位不是企业、不是展厅、不是政府窗口——它是一个**生态基础设施**。来这里不是"看鸿蒙产品"，而是"看鸿蒙怎么被组织和推广"。它回答的问题不是"鸿蒙能做什么"，而是"鸿蒙为什么能在广东做成产业"。

**关键概念：**

| 概念 | 一句话解释 |
|------|-----------|
| 适配认证 | 企业产品接入鸿蒙生态前，需通过中心的技术兼容性测试和认证——类似"鸿蒙生态的3C认证" |
| 北向/南向适配 | 北向 = 应用软件适配鸿蒙系统；南向 = 芯片、模组、板卡等硬件适配鸿蒙 |
| "一中心+三基地" | 黄埔总部管标准、发认证、做决策；东莞/佛山基地贴近产业集群做落地服务 |
| 全栈式 | 从芯片→板卡→整机→应用层，整个链条都能在中心完成适配，不用跑多个地方 |
| 技术委员会 | 19位专家组成的决策机构，决定适配标准、技术路线——是中心真正的"大脑" |

> "进去之后，把自己当成一个'产业观察者'而不是'参观者'。看墙上挂了哪些企业的认证证书、展厅里摆了哪些行业的样机、工作人员嘴里最高频的词是什么——这些比官方介绍更真实。"

## 第一阶段：生态展厅参观

**目的：快速建立对中心能力版图的直观认知。注意看什么被放在C位、什么被一笔带过。**

| 观察点 | 具体看什么 | 为什么重要 |
|--------|-----------|-----------|
| **展厅C位** | 一进门最显眼位置放的是哪个行业的产品/方案？ | 反映中心当前最主推的方向 |
| **认证证书墙** | 拍下来——已发多少张证？哪些企业？什么产品？ | 这是适配进度的最硬证据 |
| **合作伙伴logo墙** | 数一数多少家、哪些行业的公司、有没有你认识的东莞企业 | 看生态覆盖广度，以及东莞在其中的分量 |
| **九大领域展示** | 交通/电力/教育/医疗/政务/应急/城市更新……每个领域各有什么？哪个展区最大？ | 验证"九大领域"是否均衡发展，还是侧重某几个 |
| **东莞相关展示** | 有没有东莞企业/产品/案例出现？ | 直接为报告找"省级平台↔东莞落地"的关联证据 |
| **人才/培训展示** | 有没有培训教室、认证考试区、教材/课程体系展示？ | 验证"100+院校、1万人次"的落地程度 |

**全程留意：**
- 工作人员介绍时哪个词出现最频繁——"标准"、"生态"、"安全"、"政策"？
- 有没有数据大屏？上面实时显示什么指标？
- 展厅有没有"互动体验"还是纯展板？——反映中心的运营理念偏"展示"还是"服务"

## 第二阶段：座谈访谈


### 八个核心问题（45分钟）

|  | 问题 | 追问方向 | 负责 |
|---|------|---------|------|
| 1 | 省适配中心"公益性质+企业化运作"，具体怎么理解？运营模式和盈利逻辑是什么？ | 政府拨款 vs 服务收费占比？盈亏平衡了吗？ | |
| 2 | 一个企业要把产品做鸿蒙适配认证，从头到尾走什么流程？典型周期多长？花多少钱？ | 不同行业差异大吗？大企业 vs 中小企业流程一样吗？ | |
| 3 | 你们和东莞滨海湾的国家AI中试基地都叫"适配中心"——两家怎么分工？是上下级、互补、还是竞争？ | "一中心+三基地"里的东莞基地和国家AI中试基地又是什么关系？ | |
| 4 | 九大重点领域，哪些推进最快？哪些推不动？瓶颈在哪？ | 推进快的领域是因为政策强推、市场有需求、还是技术最成熟？ | |
| 5 | "一中心+三基地"跨城协同，实际操作起来顺不顺？佛山基地和东莞基地各侧重什么？ | 广州黄埔总部的决策，到东莞基地执行，中间有没有衰减？ | |
| 6 | 你们这套适配标准和认证体系，能复制到外省吗？有没有外省来取经的？ | 广东模式的核心竞争力是什么——离华为近？制造业集群？政策力度？ | |
| 7 | 收费标准怎么定？中小企业做一次适配认证大概多少钱？他们负担得起吗？ | 有没有因为费用问题放弃适配的案例？有没有补贴或减免政策？ | |
| 8 | 适配至今，企业提交适配申请最常见的失败原因是什么？最大阻力来自技术、成本还是意愿？ | 有没有企业适配到一半放弃的？原因是什么？ | |

### 追问技巧

- **挖数据**：对方提到任何数字（"很多企业""不少案例""逐渐增长"）→ 立刻追问具体数字
- **挖案例**：对方提到某家企业 → 追问"能具体说说吗？"
- **挖矛盾**：对方说"推进顺利" → 追问"那最难啃的骨头是什么？"
- **挖东莞**：任何提到东莞的地方 → 追问"东莞在省里的定位是什么？特殊在哪？"
