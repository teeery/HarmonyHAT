## 场景前置信息（出发前发给全员）

华为全屋智能授权体验店，不是卖手机的——是卖"一整套鸿蒙智能家"的。店内搭建了完整的居家实景：玄关、客厅、餐厅、卧室、卫浴。所有灯光、窗帘、空调、音响、门锁、传感器通过鸿蒙系统联动。

**为什么非晚上不可？** 白天店里光线充足，PLC灯光渐变的顺滑度、AI传感器在暗光下的灵敏度、睡眠模式的氛围、起夜微光的触发距离——这些白天完全试不出来。晚上9点人最少，店员最闲，愿意带你慢慢走完整条动线。

**关键概念：**

| 概念 | 一句话解释 |
|------|-----------|
| PLC有线+无线双网 | 鸿蒙智家的通信骨架——PLC走电力线（稳定不掉线），WiFi走大带宽（视频/音乐）。比纯无线方案可靠 |
| AI超感传感器 | 装在天花板上的毫米波雷达，能检测到人在哪个房间、是静止还是移动、甚至呼吸频率——不需要摄像头 |
| 场景联动 | 一个指令触发一串动作。比如"观影模式"= 关主灯 + 窗帘拉合 + 氛围灯带亮 + 投影仪开 |
| 起夜微光 | 传感器检测到你下床→过道地脚灯自动微亮→卫生间灯亮→回床后全部熄灭。全程不用摸开关 |
| 一屏控全屋 | 墙上中控屏或手机App，一个界面控制全家所有鸿蒙设备 |

**为什么这个场景重要？** 这是你们四个场景里唯一一个"家庭空间"——汽车是移动空间、商圈是公共空间、全屋智能是私人空间。你们可以在报告里形成"移动→公共→私人"的鸿蒙全场景闭环。

## 第一阶段：到店 + 建立关系（21:00 — 21:03）



> "你好，我们是大学生做社会实践调研，想了解一下鸿蒙全屋智能。能带我们走一遍完整的'回家→客厅→卧室→起夜'动线吗？大概20分钟就行。"

**为什么这么说？** "完整动线"告诉对方你要的不是随便逛逛；"20分钟"让对方放心你不会赖着不走；"社会实践调研"说明你不是来蹭空调的。

如果店员犹豫，补一句："我们可以自己看，你方便的时候给我们讲几句就行。"

## 第二阶段：跟随动线体验（21:03 — 21:25）

### 动线顺序（跟着店员走，全员一起）

| 场景 | 店员演示时你要注意的 | 触发方式 | 预计耗时 |
|------|--------------------|---------|---------|
| **① 玄关进门** | 开门方式（指纹/人脸/手机NFC？）、进门后自动亮灯的逻辑（全亮还是仅玄关亮？）、离家布防怎么触发 | 店员操作或让你试 | 3 min |
| **② 客厅·多场景切换** | 让店员依次切：会客模式→观影模式→阅读模式→全关。重点看灯光变化是"啪的一下"还是"缓缓渐变"；窗帘开合噪音；不同模式之间的切换延迟 | 语音"小艺管家" 或 中控屏一键切 | 5 min |
| **③ 餐厅/厨房** | 有没有燃气/水浸传感器展示？报警时怎么联动（灯光闪烁+手机推送+自动关阀？） | 店员演示 | 3 min |
| **④ 卧室·睡眠模式** | **这是今晚最重要的测试项。** 让店员关掉展厅所有灯，切"睡眠模式"→观察：灯光是瞬间灭还是模拟日落渐变？窗帘是否完全闭合？全屋哪些设备自动进入休眠？ | 中控屏或语音触发 | 4 min |
| **⑤ 卧室·起夜微光** | **只有在暗光环境下才能测。** 从床区走出来→地脚灯多久亮？亮度够不够看清路但不刺眼？进卫生间后灯是自动亮还是需要开关？回床后灯多久自动灭？ | AI传感器自动触发（不需要任何操作） | 4 min |
| **⑥ 卧室·晨起模式** | 让店员切"晨起模式"→窗帘是否缓缓打开？灯光从暗到亮是否模拟日出？背景音乐是否自动播放？ | 中控屏定时或语音触发 | 3 min |

### 全程每个人在心里打分（不用说出来）

每切换一个场景，心里记一个1-5分：
- 5分 = "如果我家装修，我一定要装这个"
- 3分 = "不错但可有可无"
- 1分 = "比我手动开关还麻烦"

## 第三阶段：自由复测 + 追问（21:25 — 21:33）

店员带完动线后会站在旁边等你们。这8分钟是关键窗口——

### 每个人回头重测自己最在意的一项

| 如果你对这件事最在意 | 回头再做一次 |
|---------------------|------------|
| 灯光渐变是否顺滑 | 让店员重新切一次"观影→全关→观影"，录一段5秒视频 |
| 起夜微光灵敏度 | 从床区走出来2-3次，测传感器触发距离和延迟 |
| 语音助手好不好用 | 离开3米远说"小艺管家，打开窗帘"——测远场拾音 |
| PLC到底稳不稳 | 问店员："客户装完后断连过吗？WiFi方案和PLC方案返修率差异？" |

### 队长追问（找店员聊2分钟，其他人围观即可）

> "来你们店里体验的客户，最后有多少人会下单全屋智能？"
> "最常被客户吐槽的一点是什么？"
> "装一套三房两厅的全屋智能大概多少钱？"

**记录店员的原话**——这三句引语放进报告比任何技术分析都有说服力。

## 第四阶段：门口快速复盘（21:33 — 21:40）

不占用店内空间，走到店门口走廊，站7分钟每人一句话：

### 复盘模板

1. "六个场景里我打分最高的是___（几分），因为___"
2. "如果我家装修，我一定会装的是___，一定不会装的是___"
3. "和今晚寮步的鸿蒙座舱相比，全屋智能给普通人的感觉是更'看得见'还是更'看不见'？"

### 你现场收束

统计一下：

- 六场景里得分最高的是哪个？（大概率是"起夜微光"——因为只有这个是"不用任何操作，系统主动服务"）
- 六场景得分最低的是哪个？（大概率是"语音控制"——因为对着空气说话尴尬）
- 有多少人说了"我一定不会装"？（如果比例高，追问一句："是不想装，还是装不起？"——这是两个完全不同的结论）

### 补拍（如果刚才没来得及）

| 素材 | 要求 |
|------|------|
| 中控屏主界面特写 | 亮屏状态，显示全屋设备列表 |
| 展厅全景一张 | 暗光环境，灯光场景正在运行中 |
| 起夜微光实拍 | 暗光条件，地脚灯亮起，拍出"微光"的感觉 |
| 店员演示时的侧拍 | 双方自然交流状态 |

## 当晚联动复盘（回到酒店后·5分钟）

> 今天一天走了三个鸿蒙场景：寮步汽车城（移动空间）→ R&A PARK（公共空间）→ 全屋智能（私人空间）。

你问全员一个问题：

**"从'鸿蒙离我有多近'这个维度，三个场景排个序。"**

大概率结果是：汽车 > 商圈 > 全屋智能。因为汽车座舱鸿蒙是"直接能摸到的"，商圈鸿蒙是"有些能看到有些看不到"，全屋智能是"不装修就跟我没关系"。

这个排序本身就可以当作你们报告的一个核心发现——**"鸿蒙在消费端的感知度随场景私密性递增而递减"**。
