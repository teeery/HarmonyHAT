#### 参访关注点

1. **产业集聚逻辑**：南城为什么要把鸿蒙企业聚在一起？"数字经济十条"给了什么真金白银的支持？
2. **鸿蒙生态大厦**：规划到什么阶段了？预计引入哪些类型的企业？
3. **入驻企业画像**：目前已有多少家鸿蒙相关企业入驻？规模、行业分布如何？
4. **园区服务**：产业园给入驻企业提供什么服务？（适配支持？政策申报？人才招聘？）
5. **与滨海湾、松山湖的分工**：东莞这么多产业园区都在做鸿蒙，湾区数谷的差异化定位是什么？

#### 听讲解 + 亲身体验

专员全程带领，先听整体介绍，再上手实测。以下是要重点关注和提问的方向。

**向专员请教的几个问题**

1. 鸿蒙AI智办区从立项到落地的决策过程是怎样的？首批为什么选这3个事项上线？
2. 后台与原有政务系统（各委办局）的接口改造难度大吗？鸿蒙终端怎么对接异构系统？
3. 上线以来市民反馈怎么样？高频问题或投诉集中在哪些方面？
4. 中老年群体对鸿蒙设备的操作门槛如何？有没有配套的引导措施？
5. 下一阶段还计划进驻哪些事项？最终50个事项的优先级排序逻辑是什么？
6. 鸿蒙"碰一碰"对不同品牌/型号手机的兼容性覆盖到什么程度了？

**自己体验时留意**

| 体验项 | 感受记录 |
|------|------|
| 进厅取号——鸿蒙手机靠近闸机是否自动弹出取号？响应速度？ | |
| 碰一碰办理——NFC识别是否灵敏？信息填充是否自动完成？ | |
| 跨设备协同——手机⇄柜台大屏⇄电脑，流转是否顺畅？ | |
| 全流程——从进厅到办结总耗时？比传统窗口省了多少步？ | |
| 指引——标识是否清晰？第一次来的市民能不能自己搞定？ | |
