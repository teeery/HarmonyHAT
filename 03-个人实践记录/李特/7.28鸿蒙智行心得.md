# 7.28 鸿蒙智行调研实践心得

## 一、调研概况

- **时间**：2026年7月28日
- **地点**：寮步国际汽车城
- **体验车型**：问界M9（纯电）、奔驰GLA（燃油）
- **调研重点**：座舱体验 + 驾驶体验 + 同价位对比

---

## 二、座舱体验

6项鸿蒙座舱功能实测：

| 测试项 | 结果 | 简单评价 |
|--------|------|----------|
| 导航流转 | 手机开导航上车，中控有弹窗但有可见的延迟 | 不够灵敏 |
| 音乐流转 | 没账号，没法测 | — |
| 语音助手 | 单操作大纲2秒响应，多操作也能准确响应 | 挺快，好用 |
| 超级终端 | 没账号，没法测 | — |
| 手表联动 | 没设备，没法测 | — |
| 流畅度 | 滑动、缩放、切换都正常 | 日常够用 |

测下来感觉:

- 语音助手是最大的亮点，响应快、识别准。
- 流转功能想法很好（手机⇄车机无缝切换），但实际体验有两个门槛：
  - 账号门槛：没登录华为账号，大部分流转功能根本试不了。
  - 生态门槛：车机上能用的鸿蒙应用还很少，不够丰富。
- 我觉得门店或者销售应该备一个演示账号，不然非鸿蒙客户来会体验不到完成能力。

## 三、驾驶体验对比

### 3.1 方向盘

| 问界M9 | 奔驰GLA |
|--------|---------|
| 方向盘很轻，一根手指都能转 | 方向盘偏重，有分量感 |

轻重各有好处。M9的轻能让人开车轻松省力，奔驰追求的是操控感和路感。感觉是两种派别的思路——科技帮你开车舒适 vs 让你享受开车操纵感。

### 3.2 隔音

| 问界M9 | 奔驰GLA |
|--------|---------|
| 很安静，车里几乎听不到外面。但是车内的智能隔音功能一般没有起到很好的隔音作用 | 一般，能听到发动机和风噪，在跑高时速时仍能听到一些窗外噪声 |

有可能是电车没有发动机噪音，本来就安静一些，而且两辆车的价位不同，对比上有位差。但M9的隔音确实下了功夫，在静谧性上超过了传统豪华品牌。

### 3.3 智能驾驶

| 问界M9 | 奔驰GLA|
|--------|---------|
| 城镇道路也能用，覆盖广 | 只能在高架上用辅助驾驶 |

智驾体感差距较大，M9的智驾已经能日常能用，高速还没试过，奔驰的基本只是高速巡航辅助，在这次试驾中，有个情况奔驰处理的一般，在一个汇路口侧有来车时降速很快，但是后方的速度并不低，在几秒内从50降到了30，并不是一个安全的做法，此时前方并无车辆，我觉得更好的做法应该是打双闪慢慢减速让来侧旁车。

### 3.4 两套智驾系统的技术底子

搜索了两套系统的技术方案:

#### 问界M9：华为乾崑ADS 5

| 项目 | 说明 |
|------|------|
| 系统名称 | 华为乾崑智驾 ADS 5 |
| 传感器数量 | 约40个（含6颗激光雷达） |
| 核心感知 | 前向896线主激光雷达 + 前向冗余激光雷达 + 4颗固态激光雷达（全向） + 4D毫米波雷达 + 多摄像头 |
| 软件架构 | BEV+Transformer感知 + 盘古大模型训练 + 端到端演进 |
| 地图依赖 | 无图化，不依赖高精地图 |
| 覆盖场景 | 高速/城区NOA、车位到车位全场景、自动泊车 |
| 累计里程 | 超91亿公里辅助驾驶里程（截至2026年5月） |
| L3进度 | 2025年底已开启高速L3内测，2026年推动规模商用 |

硬件堆得很满，用多颗激光雷达做安全冗余，软件靠海量真实路跑数据训练，目标是L3级自动驾驶。

#### 奔驰GLA：Mercedes-Benz Driving Assistance（23P套件）

| 项目 | 说明 |
|------|------|
| 系统名称 | Mercedes-Benz Intelligent Drive（智能驾驶辅助套件，代码23P） |
| 核心传感器 | 多功能立体摄像头 + 远程雷达 + 侧向毫米波雷达 + 12颗超声波雷达 |
| 横向控制 | Active Steering Assist（智能转向辅助，跟车道线小幅转向） |
| 纵向控制 | DISTRONIC主动定速测距 + 启停辅助 + 基于路线的速度自适应 |
| 碰撞安全 | 主动刹车辅助（含行人/横向来车识别）、闪避转向辅助、PRE-SAFE |
| 盲区监测 | 主动盲点辅助 + 离车警示 + 后方横向车流警示（倒车时可紧急制动） |
| 泊车辅助 | 自动搜索车位、自动泊入泊出 |
| 覆盖场景 | 以高速公路和城市快速路为主，城区场景能力有限 |

传统L2级辅助驾驶，功能集中在高速巡航+主动安全+泊车，不追求城区全场景覆盖，定位是"辅助"而不是"替代"驾驶员。

#### 差距在哪

| 维度 | 问界M9（ADS 5） | 奔驰GLA（23P） |
|------|-----------------|----------------|
| 传感器 | 6颗激光雷达 + 多传感器融合 | 立体摄像头 + 雷达为主，无激光雷达 |
| 技术路线 | 重硬件冗余，为L3提前布局 | 成熟L2，以安全辅助为边界 |
| 覆盖场景 | 城区+高速+泊车，几乎全场景 | 高速巡航为主，城区仅基础安全功能 |
| 软件迭代 | OTA持续升级，数据驱动 | 年款更新为主，传统开发节奏 |
| 核心目标 | 逐步替代驾驶员 | 辅助驾驶员 |

这些技术差异也解释了试驾时的体感差距——M9的硬件底子和软件能力决定了它在城区也能跑智驾，而GLA的23P套件本质上是"高速巡航帮手 + 安全兜底"，没有城区领航的设计目标。两者不是同一代的产品。同时也不是一个价位的产品，所以不构成严谨对比，只表达不同的辅助驾驶的技术和驾驶体验。

## 四、同价位怎么看M9

M9大概50万左右，这个价位可以买BBA的中大型SUV。我的判断是：

- **智驾**：M9赢，传统品牌一些是跟不上的。
- **座舱智能化**：鸿蒙流转的想法很超前，但实际用起来还不成熟。
- **传统豪华**：内饰用料、品牌面子、音响（奔驰的柏林之声真的牛逼），传统品牌还是强。

我觉得，看重智能体验的会选M9，看重品牌和机械素质的会选传统品牌。

## 五、其他零碎的发现

### 5.1 蓝灯规则

今天才知道，电车的智驾启动后，车外会统一亮蓝灯。这是一个行业规范，提醒周围车辆和行人"这车现在是自动驾驶"。感觉是个挺好的规定，说明智驾正在从野蛮生长走向标准化。

### 5.2 柏林之声

奔驰的柏林之声音响确实厉害，听完再听M9的音响能感觉到差距。音响这种东西，不只是硬件，还有多年的调音经验，这个传统品牌有积累。

### 5.3 鸿蒙生态的尴尬

反复出现"没账号没法演示"这个问题，说明鸿蒙座舱太依赖华为全家桶。如果不是华为手机用户，流转、超级终端这些核心卖点就大打折扣。这对吸引新用户来说不是好事。

---

## 六、总结

1. M9在智能化（智驾+座舱）上确实领先于多数传统品牌，尤其是智驾，代际差距很明显。
2. 但传统豪华品牌在机械素质、音响、品牌沉淀上依然有自己的护城河。
3. 鸿蒙生态闭环是双刃剑——绑定了华为用户，也挡住了新用户了解它。
4. 个人觉得，M9代表了"车越来越像科技产品"的趋势，奔驰代表了"车首先是机械素质"的传统。两种路线没有绝对的好坏，只是面向的用户不同。
